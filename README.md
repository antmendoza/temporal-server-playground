# temporal-server-playground

Local Temporal environment for learning internals through degradation scenarios. 
Uses dynamic config to induce specific failure modes and observe them in Prometheus/Grafana.


## Stack

| Service | URL |
|---|---|
| Temporal UI | http://localhost:8080 |
| Grafana | http://localhost:3000 |
| Prometheus | http://localhost:9091 |
| Temporal gRPC | localhost:7233 |
| Elasticsearch | http://localhost:9200 |

## Getting Started

```bash
make up       # start everything
```
```bash
make logs     # follow Temporal server logs
```
```bash
make down     # stop everything
```

## Scenarios

Each scenario modifies `config/dynamicconfig/development.yaml`. 
The server watches this file and reloads on change — no restart needed.

> Scenarios have been generated by claude, not tested.

```bash
make reset                 # back to defaults
```
```bash
make scenario-visibility   # visibility write QPS capped at 5
```
```bash
make scenario-matching     # 1 task queue partition, low persistence QPS
```
```bash
make scenario-history      # history persistence QPS capped at 20
```
```bash
make scenario-frontend     # visibility API capped at 1 RPS per namespace
```

### Load generation


```bash
make tidy #compile go code
```

```bash
make worker #start worker
```

```bash
make starter w=100 a=3 c=3   # w=workflows, a=activities per workflow, c=child workflows per workflow
```
