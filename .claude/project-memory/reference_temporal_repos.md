External repositories to consult for context on Temporal server work in this project:

- **https://github.com/tsurdilo/temporal-server-operations** — Tihomir Surdilovic's collection of Temporal server operations material (operational runbooks, ops patterns).
- **https://github.com/temporalio/dashboards** — Official Temporal dashboards repo (Grafana/observability dashboards for Temporal server).
- **https://github.com/temporalio/temporal** — The Temporal server source repository itself (canonical implementation, history, and issues).

How to apply: When the user asks about Temporal server internals, operational concerns, metrics/dashboards, or wants supporting evidence for a change in this playground, consult these repos (via WebFetch or `gh`) rather than guessing or relying only on local files.
